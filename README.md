# ESP32Drift

ESP32Drift enables concurrent processing, leveraging hardware-accelerated multi-threading for real-time responsiveness and precise drift compensation on the ESP32 platform.

ESP32Drift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/ESP32Drift.git`
2. `cd ESP32Drift`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ESP32Drift, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
